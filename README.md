# EscheridiaRT
Path traced offline renderer build on bedrock edition. 
Open source project to be used for learning purposes, editing or building your own project. I would highly appreciate it if you consult me before doing so.

Original Bedrock RTX Shader Template can be found here: https://github.com/veka0/mcrtx-shader-template this link will also provide instructions on how to set up your pipeline, what is necessary and how to compile rtx projects.
